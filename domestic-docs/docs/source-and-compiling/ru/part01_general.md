# Основные положения

Описание технических средств хранения исходного текста и
объектного кода программного обеспечения, а также технических
средств компиляции исходного текста в объектный код
программного продукта «CraneWare.Registrator» (далее Продукт).

- Исходный и объектный код Продукта хранится по Адресу разработчика, подтверждается договором аренды (см. приложения)
