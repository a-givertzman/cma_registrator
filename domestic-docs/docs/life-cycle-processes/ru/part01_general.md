# Основные положения

Документ определяет процессы, виды деятельности и задачи, которые используются при разработке, поставке, сопровождении и прекращении применения программного продукта «CraneWare.Registrator» (далее продукт).

Системная и программная инженерия. Процессы жизненного цикла программных средств»](/reference/ru/ISO/ГОСТ-12207-2010.pdf)).
