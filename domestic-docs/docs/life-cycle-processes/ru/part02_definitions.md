# Определения

| Термин                                                    | Определение                                                                                                                                                                 |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Адаптация продукта для работы с грузоподъемным механизмом | Разработка версии продукта и набора исходных данных по конкретному грузоподъемному механизму, которое является предметом поставки по договору с приобретающей стороной      |
| Деятельность (по ISO/IEC 12207:2008)                      | Совокупность согласованных задач процесса                                                                                                                                   |
| Процесс (по ISO/IEC 12207:2008)                           | Совокупность взаимосвязанных или взаимодействующих видов деятельности преобразующих входы в выходы                                                                          |
| Выход процесса (по ISO/IEC 12207:2008)                    | Наблюдаемый результат успешного достижения цели процесса                                                                                                                    |
