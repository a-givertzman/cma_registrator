# Описание интерфейса
## Экран с базовой информацией
![Страница c базовой информацией](/assets/image/program_sheets/ru/sheet01_common_info/common_info.png "Страница c базовой информацией")

На данном экране информация организованна в 3 столбца:
- идентификационные данные грузоподъемного механизма;
- идентификационные данные регистратора;
- данные о наработке грузоподъемного механизма.

## Рабочие циклы
![Рабочие циклы](/assets/image/program_sheets/ru/sheet02_working_cycles/working_cycles.png "Рабочие циклы")

Регистратор параметров определяет границы начала и завершения рабочих циклов и прикрепляет рабочие метрики грузоподъемного механизма к этим циклам. Подробнее узнать о распределении событий в рабочем цикле можно, соверши двойной щелчок по одной из записей в таблице рабочих циклов.

Рабочие циклы по желанию можно отфильтровать.


## События и метрики
![Метрики и события цикла](/assets/image/program_sheets/ru/sheet03_certain_cycle/certain_cycle.png "Страница метрик циклов")

Данный экран содержит все события, которые произошли за временной период рабочего цикла. По некоторым параметрам сверху экрана агреггируются метрики.

События рабочих циклов по желанию можно отфильтровать.
