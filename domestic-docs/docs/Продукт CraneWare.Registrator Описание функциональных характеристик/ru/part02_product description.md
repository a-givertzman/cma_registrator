# Описание программного продукта
CraneWare.Registrator — программный продукт, выступающий в качестве регистратора параметров для грузоподъемных механизмов.
Предназначен для сбора и подсчета информации о перемещении грузов, вычисления наработки как отдельно для каждой из лебедок, так и для самой машины в целом. Такие данные помогают в предупреждении аварийных ситуаций в будущем.
