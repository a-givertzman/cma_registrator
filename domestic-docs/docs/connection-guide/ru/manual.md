## Подключение на ПК с Windows:

В поле поиска на панели задач введите **Подключение к удаленному рабочему столу** (en. **Remote Desktop Connection**) и выберите **Подключение к удаленному рабочему столу**. В окне "Подключение к удаленному рабочему столу" введите имя компьютера, а затем нажмите кнопку **Подключиться**.

Введите имя и пароль пользователя.

## Взаимодеиствие с окружением:

Внизу рабочего стола расположена панель для быстрого запуска доступных приложений (слева направо): клиент **CraneWare.Registrator**, файловый менеджер **Thunar** и **Терминал**.

Пользователю предоставлен аккаунт с правами суперпользователя (root доступ). Если для выполнения команд, требующих права суперпользователя, будет запрошен пароль необходимо воспользоваться тем же паролем, который использовался для подключения по RDP.


## Структура файлов приложения:

Для удобства просмотра всех файлов приложения, они расположены в директории `/config` со следующей иерархией:

```
/
└── config
    ├── craneware-client    # Директория с файлами клиента CraneWare.Registrator
    │                       # для графического интерфейса
    │
    ├── craneware-db        # Директория с файлами базы данных для приложения CraneWare.Registrator
    |
    │
    ├── craneware-server    # Директория с бэкэнд составляющей приложения CraneWare.Registrator.
    │                       # Сюда входят модуль опроса ПЛК, сохранения событий
    │                       # и сервер для взаимодеиствия между всеми частями приложения
    │
    └── startwm.sh          # Конфигурационный файл для RDP окружения,
                            # не относится к файлам приложения, просьба не редактировать
```
