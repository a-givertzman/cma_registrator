# Настройка тензодатчика
## 1. Калибровка нуля
Чтобы настроить 0, нужно снимать нагрузку с тензодатчика до тех пор, пока на экране приложения не покажет 0 кг.
![Страница калибровки тензодчатчка](/assets/image/program_sheets/ru/sheet04_tensosensor_calibration/tensosensor1st.png "Страница калибровки тензодчатчка")
## 2. Калибровка для заданного веса
Для этого мы оказываем предметом заданного веса нагрузку на тензодатчик, далее смотрим на экран и изменяем настройку тензодатчика до тех пор, пока вес на экране не сравняется с желаемым.
![Страница калибровки тензодчатчка](/assets/image/program_sheets/ru/sheet04_tensosensor_calibration/tensosensor2nd.png "Страница калибровки тензодчатчка")
